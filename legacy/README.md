# Preserved original code — provenance only

These are original scientific scripts, retained without path or analytical edits. The kill-test was decoded from the original batch wrapper; its decoded digest is recorded in `docs/source_manifest.json`.

**Do not execute these files directly.** They contain obsolete absolute paths, writes to existing workspaces, and an inherited patient-repair routine that deletes an existing backup. Use the supported CLI, which requires a new output directory; its repair adapter refuses an existing backup instead of deleting it.

The copies preserve historical defects and scientific logic for review. Their presence does not certify each script as safe or correct for arbitrary datasets. Earlier fixed wrappers and renal-atlas packages remain intact in the canonical local project and are inventoried locally; they are not part of the supported release path.

Original line endings are retained. Git whitespace normalization/checking is disabled only for these byte-preserved Python snapshots; their SHA-256 digests are tested instead.
